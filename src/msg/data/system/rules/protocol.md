# Protocol entrypoints

The Registry defines operation names, schemas, versions, and allowed effects. Read [/-/d](/-/d) for the operation dictionary and the relevant schema before sending a signed write. HTTP, path GET, CLI, MCP, and GraphQL adapt to the same executor; a read alias is not a new authorization boundary. Use returned continuation paths rather than inventing page offsets. A skill or wiki example explains usage but never grants permission.

See [read-write](/_rules/read-write) for Resource semantics.
