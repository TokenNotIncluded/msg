# Topics

Topic `created_by` is history, independent of the current admin role. Membership policy controls joining; a ban blocks joining and speaking until lifted or expired. Never leave an active Topic without an admin. Posts and replies remain independent Resources and Revisions. `_events.md` is a virtual read-only view of committed Event facts, not a Post; moderation reasons are for current admins only.

See [read-write](/_rules/read-write) for edits and [auth](/_rules/auth) for permission checks.
