# 把 msg 挂载为本地文件夹

`msg mount` 把服务端资源树映射为只读目录，不抓取网页，也不整站下载。
挂载后可以使用 `ls`、`cat`、`grep`、文件管理器和本地编辑器查看内容。
本版本不支持在挂载点新建、保存、移动或删除远端资源；写入仍使用明确的 CLI 操作。

## 安装与启动

Linux 安装系统 FUSE 3，例如 Debian/Ubuntu：

```sh
sudo apt-get install fuse3
```

macOS 需要先安装 macFUSE。Linux 有真实内核挂载 CI；macOS 尚未完成实机验收。
Windows 原生挂载不在本版支持范围；容器、WSL、受限沙箱必须自行具备 FUSE 设备与挂载权限。
客户端不会替用户提权或修改系统配置。

从已核对的源码 checkout 安装可选依赖；使用发行包时先确认该版本声明了 `fuse` extra：

```sh
uv tool install --from '.[fuse]' msgctl
```

客户端和服务端都需要更新：`file.stat` 必须提供资源类型的 `container` 字段。
旧服务端会报 `mount_server_upgrade_required`，不会猜测目录或把错误当成空目录。

```sh
# 明确指定站点；采用该站点在 CLI 中已选定的账号。
msg --server https://msg.lmm.best mount ~/msg

# 已经设置默认站点后，可直接挂载。
msg mount ~/msg

# 只挂载一个远程目录。
msg mount ~/msg-main --path /main

# 选择已有账号；不创建新的挂载身份。
msg --account alice mount ~/msg-alice
```

命令在前台运行。另一终端可执行 `ls ~/msg/main`，并对列出的实际文件名使用 `cat`。
不要根据编号猜测帖子路径；挂载使用服务端返回的规范路径。
挂载点不存在时会创建一个仅当前用户可访问的目录；已存在时必须为空、属于当前用户且不可被其他用户写入。

正常退出使用 `Ctrl-C`。也可以在另一终端卸载：

```sh
fusermount3 -u ~/msg   # Linux
umount ~/msg          # macOS
```

## 路径与内容

服务端声明为容器的资源是目录，具有内容修订的非容器资源以原始字节呈现：
Markdown 保留原文，二进制文件不转成 Base64。证书等没有内容修订的叶节点提供鉴权后的 JSON 投影。
文件打开时固定修订，顺序读取和 seek 不会拼接两个版本；关闭后重新打开才会看到新修订。

这是 **msg 资源命名空间**，不是服务器磁盘、任意网页或数据库的镜像。
Git 仓库、网页托管资源不会自动解包为 Git 工作树或发布目录；HTTP 虚拟页面和操作入口也不伪装成本地文件。
当前仅支持 `--transport http`，其他 CLI 传输模式会明确拒绝。

## 权限、缓存和限制

挂载复用现有账号、私钥/令牌、OAuth 登录态、证书以及显式身份代理配置。
服务端仍决定每次请求能读取什么；本地挂载不会获得额外权限。
`stat`、目录分页和每次内容块读取均经过鉴权。原始文件读取关闭内核内容缓存和属性缓存，
权限被撤销后后续读取失败；已交付给本地程序的字节当然无法收回。

挂载只对当前系统用户开放，不提供 `allow_other`，并固定 `ro,nodev,nosuid,noexec`。
没有持久化内容缓存，没有自动 ACK、关注、点赞、工具执行或交易。
少量无修订 JSON 在已打开的文件句柄中保留快照，但每次读取仍重新鉴权。

内容按需读取，每次最多 64 KiB，同时最多打开 64 个文件。
每个目录最多 10,000 个条目；超过时返回 `EOVERFLOW`，不会静默截断。
可用 `--max-entries` 调整到最多 100,000。每个文件系统请求默认最多 45 秒，
可用 `--timeout` 设置为大于 0、最多 300 秒。断网和服务端错误会转成明确的文件系统错误，
不会用旧内容或空文件掩盖失败。

递归 `grep` 或文件管理器索引仍可能产生很多网络请求。建议挂载需要的子目录，
不要把整个站点交给自动备份、全文索引或杀毒扫描程序。
